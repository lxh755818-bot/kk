# 飞书群聊 @ 机制

> 来源：2026-04-29 刘氏三虾群实测验证
> 技能等级：Core（核心技能）
> 维护人：小a

---

## 1. 核心结论（速查）

**一句话执行准则**：飞书群内 @Agent 必须用 `<at user_id="">显示名</at>` XML 标签；被 @回复时需携带发起方 @标签发回原群，形成**对话闭环**。

| 参数 | 强制要求 | 校验规则 |
| ------- | ---- | ------------------------------ |
| `<at>` 标签 | 是 | 完整闭合，无嵌套，仅保留 user_id 属性 |
| user_id | ✅ 必须填写 | 必须以 `ou_` 开头，32位十六进制字符串。**id留空只显示蓝色但不推送通知** |
| 群 ID | 是 | 必须以 `oc_` 开头 |
| **@前后必须有文字** | ✅ 关键 | `<at>` 标签前后必须有文字包裹，否则飞书可能不投递通知 |
| 群聊直接发消息 | 是 | 不需要私聊，群里发消息即可 |

**✅ 正确格式**
```
你好<at user_id="ou_5de19270f8825dae4fd13f9f19d229ef">刘二虾</at>，在吗？
```

**❌ 错误格式**
- 普通 `@名字` → 不触发
- `<at user_id="">名字</at>` → 显示蓝色但**不推送通知**
- @前后无文字：直接`@刘二虾`（裸@失效）

---

## 2. 格式规范详解

### XML 标签结构

```xml
<at user_id="ou_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx">显示名</at>
```

- **user_id**：必须以 `ou_` 开头，32位十六进制字符串
- **显示名**：飞书内显示的名字
- **前后文字**：必须有，可以是空格或其他文字

### 为什么 user_id 不能留空

| 写法 | 显示效果 | 是否推送通知 |
| ---- | -------- | ------------ |
| `<at user_id="ou_xxx">刘二虾</at>` | 蓝色字体 ✅ | ✅ 推送 |
| `<at user_id="">刘二虾</at>` | 蓝色字体 ✅ | ❌ 不推送 |
| `@刘二虾` | 黑色普通文字 | ❌ 不触发 |

## 4. 全链路操作步骤

### 发起方（@别人）
1. 从通讯录获取对方的 `open_id`
2. 构造消息：`文字<at user_id="ou_xxx">名字</at>文字`
3. 直接发到群里（不需要私聊）

### 被@后回复（闭环）
1. 提取发起方 `open_id`
2. 构造回复：`<at user_id="ou_xxx">发起方名字</at> {回复内容}`
3. 发回原群 → 完成闭环

## 5. 群聊特点（实测结论）

- ✅ 机器人在群里，@ 能正常触发通知
- ✅ 群消息事件正常推送到当前会话
- ✅ 回复必带 @ 对方即可完成闭环
- ✅ 不需要私聊，群里直接发消息
- ✅ 不需要在群里做任何特殊配置

## 6. openclaw.json 群配置要求（参考）

```json
"accounts": {
  "liu2": {
    "groupPolicy": "allow",
    "groupAllowFrom": ["*"],
    "groups": { "*": { "enabled": true } }
  }
}
```

| 配置项 | 必需 | 说明 |
| -------------- | --- | ------------------- |
| groupPolicy | ✅ | 设为 `"allow"` |
| groupAllowFrom | ✅ | 设为 `["*"]` |
| groups["*"] | ✅ | `"*"` 表示允许所有群 |

**常见坑**：`groupPolicy: "deny"` → 完全忽略群消息

---

## 8. Bot-to-Bot Relay 原理

飞书限制：Bot 之间消息不触发事件。

OpenClaw 解法：Hook 拦截 → 解析 `<at>` 标签 → 构造合成事件 → sessions_send 转发 → 回传结果

---

## 9. 错误排查

| 问题 | 原因 | 解决方案 |
| ---- | ---- | -------- |
| @不响应 | groupAllowFrom 问题 | 检查 openclaw.json |
| 显示蓝色但不通知 | user_id 留空 | 必须填真实 open_id |
| 通知正常但无回复 | 未带 @回闭环 | 回复必须 @ 对方 |
| DM 正常但群 @ 不工作 | 配置问题非 bug | 实际在群里 @ 测试最直接 |
